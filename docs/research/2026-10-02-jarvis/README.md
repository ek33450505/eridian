| File | Question |
|---|---|
| `q1-desktop-app.md` | CLI vs menu-bar helper vs cast-desktop panel vs full app (mic permission, packaging, always-on) |

| `q3a-speaker-verification.md` | On-device speaker verification models, licences, enrollment |
| `q3b-comparables.md` | Features of comparable voice assistants |
